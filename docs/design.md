# 設計の方針

ほのぼのとしたドット絵の経営シミュレーションで、ネットワークを設計・構築するゲームを作る。対象は、ネットワークの初心者からネットワークスペシャリスト試験の受験生までとする。最も大切にする体験は、設計したネットワークがつながる瞬間である。

序盤は手軽さを優先し、進むほど実際の設計に近い判断を求める。PC のブラウザを主とし、スマートフォンでも一通り遊べるようにする。失敗はゆるめに扱い、疎通テストは何度でも実行できる。機器は汎用の架空製品とする。

新しい仕組みは、この体験に役立つ場合に追加する。論点ごとに教材と依頼を対で作り、新しい概念は1つずつ出す。修理の依頼の文面には症状を書く。

シミュレーションは、依頼や教材で利用者が判断する挙動を作る。時間の経過は省き、結果だけを求める。挙動は現実のネットワークに合わせる。

見た目は素朴に保ち、状態の変化を吹き出し・アイコン・LED で表す。素材と UI は本作のオリジナルとする。画面の色は `src/components/ui/tokens.css` のトークンで決める。ボタンは、役割に合わせて `primary`・`secondary`・`danger`・`outline` から選ぶ。
