# 設計の方針

ほのぼのとしたドット絵の経営シミュレーションで、ネットワークを設計・構築するゲームを目指す。対象はネットワークの初心者からネットワークスペシャリスト試験の受験生までとし、設計したネットワークがつながる瞬間を最も大切にする。序盤は手軽さを優先し、進むほど実際の設計に近い判断を求める。

新しい仕組みは、この体験に役立つ場合に限って追加する。論点ごとに教材と依頼を対で作り、新しい概念は1つずつ出す。修理の依頼には症状だけを書き、原因は書かない。

シミュレーションは、依頼や教材で利用者が判断する挙動だけを作り、時間の経過は作らずに結果だけを求める。挙動は現実のネットワークに合わせる。

見た目は派手な演出を使わず、状態の変化を吹き出し・アイコン・LED で表す。素材と UI はすべて本作のオリジナルとする。画面の色は `src/components/ui/tokens.css` のトークンで決め、ボタンは役割で種類（`primary`・`secondary`・`danger`・`outline`）を選ぶ。
