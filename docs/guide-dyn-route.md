
## RIP・OSPF・BGPを試す

動的ルーティングは、タイトル画面の「サンドボックス」で試すのがおすすめです。案件では固定された機器や設定があり、自由に構成できないことがあります。

### 共通の準備

1. サンドボックスを開始する。
2. ルーターを2台置き、ルーター同士をLANケーブルでつなぐ。
3. ルーターの間のネットワークを `10.0.12.0/30` として設計する。
   - ルーターAの接続口: `10.0.12.1 / 30`
   - ルーターBの接続口: `10.0.12.2 / 30`
4. ルーターA側にPCを置き、PCを `192.168.1.10/24`、ゲートウェイを `192.168.1.1` にする。
5. ルーターB側にPCを置き、PCを `192.168.2.10/24`、ゲートウェイを `192.168.2.1` にする。
6. ルーターAの別の口を `192.168.1.1/24`、ルーターBの別の口を `192.168.2.1/24` にする。

ルーターの口番号は、設定した機器の背面で確認します。以下の例では、`0` がPC側、`1` がルーター間の口です。実際の配線に合わせて番号を読み替えてください。

`10.0.12.0` はネットワークアドレスなので、ルーターの口には設定しません。口の設定画面では、ポート番号とIPアドレスを入力するか、ターミナルで次のように入力します。

設定画面で「詳しく」を開くと、ネットワークアドレスを直接入力できます。ルーター間の口ではネットワーク欄に `10.0.12.0` と入力し、プレフィックスを `/30` にしてから、利用可能なIPアドレスとして `10.0.12.1` または `10.0.12.2` を入力します。プレフィックスを変更せず `/24` のまま IP アドレスを入力した場合は、その IP からネットワークが自動設定されます。

```text
ip address 1 10.0.12.1 255.255.255.252
```

もう一方のルーターには、同じポート番号（実際の配線に合わせて変更）へ次を入力します。

```text
ip address 1 10.0.12.2 255.255.255.252
```

ここで `10.0.12.0` は、RIP・OSPF・BGP に「このネットワークを使う」と伝えるときに使います。IPアドレスを設定する値と、ネットワークを指定する値を混同しないようにしてください。

### RIPを試す

RIPは、隣り合うルーターから経路を受け取る、最も簡単な動的ルーティングです。

ルーターAのターミナルで入力します。

```text
router rip
network 192.168.1.0
network 10.0.12.0
```

`router rip` は、そのルーターで RIP を有効にします。続く `network` は、IPアドレスを設定する命令ではありません。指定したネットワークに属するポートを RIP に参加させ、そこに接続されたネットワークを隣のルーターへ知らせる命令です。

この例では、`192.168.1.0` はPC側のLAN、`10.0.12.0` はルーター間リンクです。ポートのIPアドレスは、先に `192.168.1.1` や `10.0.12.1` のように設定しておきます。`network` には、そのIPアドレスそのものではなく、サブネットのネットワークアドレスを指定します。

ルーターBでは、ネットワークを反対にします。

```text
router rip
network 192.168.2.0
network 10.0.12.0
```

2台のPCから相手のPCへ `ping` を実行し、通信できれば成功です。さらに、**ルーターAまたはルーターBのターミナル**で `show ip route` を実行すると、相手側のネットワークが `R` の経路として表示されます。PCで実行した場合は、通常は自分の直結経路 `C` とデフォルト経路 `S` だけが表示されます。

ターミナルで `ping` または `traceroute` を実行すると、通信パケットがマップ上で経路に沿って移動します。途中のルーターを通る順番と、失敗した場合に止まる場所を観察できます。

#### 4台のルーターでRIPを試す

ルーターを4台使う場合は、次のようにPCとルーターを一直線につなぎます。

```text
PC-A -- R1 -- R2 -- R3 -- R4 -- PC-B
```

各ルーターに2つの口を使います。IPアドレスは次のように設定します。`/30` のリンクでは、ネットワークアドレス（`.0`）ではなく、使用可能な `.1` と `.2` を口に設定します。

注意: `10.0.12.0/30` を4台すべてで使うわけではありません。`10.0.12.0/30` で使える機器用アドレスは `.1` と `.2` の2つだけです。`.0` はネットワークアドレス、`.3` はブロードキャストアドレスなので、機器には設定できません。隣接するルーター間リンクごとに、別の `/30` ネットワークを用意します。

| 接続 | ネットワーク | 左側の機器 | 右側の機器 |
| --- | --- | --- | --- |
| PC-A - R1 | `192.168.1.0/24` | PC-A `192.168.1.10` | R1 `192.168.1.1` |
| R1 - R2 | `10.0.12.0/30` | R1 `10.0.12.1` | R2 `10.0.12.2` |
| R2 - R3 | `10.0.23.0/30` | R2 `10.0.23.1` | R3 `10.0.23.2` |
| R3 - R4 | `10.0.34.0/30` | R3 `10.0.34.1` | R4 `10.0.34.2` |
| R4 - PC-B | `192.168.2.0/24` | R4 `192.168.2.1` | PC-B `192.168.2.10` |

PC-Aのゲートウェイは `192.168.1.1`、PC-Bのゲートウェイは `192.168.2.1` にします。各ルーターのポート番号は、実際に配線した口番号へ読み替えてください。

ルーターのIPアドレスを設定したあと、次のRIP設定を入力します。

R1:

```text
ip address 0 192.168.1.1 255.255.255.0
ip address 1 10.0.12.1 255.255.255.252
router rip
network 192.168.1.0
network 10.0.12.0
```

R2:

```text
ip address 0 10.0.12.2 255.255.255.252
ip address 1 10.0.23.1 255.255.255.252
router rip
network 10.0.12.0
network 10.0.23.0
```

R3:

```text
ip address 0 10.0.23.2 255.255.255.252
ip address 1 10.0.34.1 255.255.255.252
router rip
network 10.0.23.0
network 10.0.34.0
```

R4:

```text
ip address 0 10.0.34.2 255.255.255.252
ip address 1 192.168.2.1 255.255.255.0
router rip
network 10.0.34.0
network 192.168.2.0
```

PC-Aのターミナルから `ping 192.168.2.10` を実行します。R1、R2、R3のターミナルで `show ip route` を実行すると、遠いネットワークほど多くのルーターを経由して学習した `R` の経路として表示されます。`traceroute 192.168.2.10` では、R1からR4までの通過順を確認できます。

### OSPFを試す

OSPFは、RIPより大きなネットワークに向く動的ルーティングです。このゲームでは、OSPFのエリアは `area 0` だけを使います。

ルーターAのターミナルで入力します。

```text
router ospf
network 192.168.1.0 0.0.0.255 area 0
network 10.0.12.0 0.0.0.3 area 0
```

ルーターBでは、LAN側だけ変えます。

```text
router ospf
network 192.168.2.0 0.0.0.255 area 0
network 10.0.12.0 0.0.0.3 area 0
```

PC間の `ping` が通り、`show ip ospf neighbor` で相手ルーターが隣接として表示されれば成功です。隣接しないときは、ルーター間のIPアドレス、サブネット、OSPFのエリアが両端で一致しているか確認します。

### BGPを試す

BGPは、異なるAS（ネットワーク組織）どうしで経路を交換するためのプロトコルです。現在のゲームでは、BGPはエッジルーターで使う想定です。ショップで解禁されるエッジルーターを2台使い、ルーターAをAS `65001`、ルーターBをAS `65002` とします。

ルーターAのターミナルで入力します。

```text
router bgp 65001
neighbor 10.0.12.2 remote-as 65002
network 192.168.1.0 mask 255.255.255.0
```

ルーターBでは、自分のAS、相手のIPとAS、広告するLANを反対にします。

```text
router bgp 65002
neighbor 10.0.12.1 remote-as 65001
network 192.168.2.0 mask 255.255.255.0
```

BGPでは、次の3つが両端でそろっている必要があります。

- `neighbor` に指定する相手のIPアドレス
- `remote-as` に指定する相手のAS番号
- 相手側の `router bgp` に設定した自分のAS番号

PC間の `ping` を試し、失敗理由が `bgp.no_session` なら、neighborのIPアドレスまたはAS番号が一致していません。BGPはOSPFのように自動で隣接を作るのではなく、相手を明示して設定します。

### うまくいかないときの確認

| 症状 | 確認すること |
| --- | --- |
| `ip.unset` | ルーターとPCの各口にIPアドレスを設定したか |
| `iface.none` | `network` のネットワークが、実際の口のIPと同じサブネットか |
| `ospf.no_neighbor` | ルーター間の配線、IP、サブネット、area 0 が一致しているか |
| `bgp.no_session` | neighborのIPとremote-asが相手の設定と一致しているか |
| 経路がない | `show ip route` と `traceroute` で、どこまで届いているか |

`show running-config` は現在の設定をまとめて表示します。設定を変えた後は、もう一度 `T` の疎通テストを実行してください。
